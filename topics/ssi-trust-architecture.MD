# Trust Architecture Document 
This document has the purpose of describing in a very concise and understandable way the **Architecture of Trust** implemented by one or more **Trust Scopes** and their **relations**. It must answer the following questions:

1. Who are all the involved Actors in each Scope
2. How the Actors in a Scope can interact with each other
3. How to extend trust across Scopes and enable inter-scope Actors' interactions
4. Require a human action in interactions between Actors
